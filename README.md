# Odoo Healthcare Management

This repository contains the `healthcare_management` module for Odoo.

## Features
- **Patients & Families**: Track medical history, genetic risks, diseases, and evaluations.
- **Physicians & Appointments**: Schedule and log calls and appointments.
- **Facilities Management**: Manage hospital buildings, wards, operating rooms, and inpatient beds.
- **Prescriptions & Medication**: Digital prescriptions with integrated sales/invoicing and stock management.
- **Lab & Imaging Tests**: Request tests and record results.
- **Surgeries & Newborns**: Pediatric care, preinatal modules, and surgery tracking.

## Installation
Add this module to your Odoo `addons` path and install it from the Apps menu.
